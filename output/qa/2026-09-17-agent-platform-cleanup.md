# agent_platform 清理实施记录

日期：2026-09-17。仅统计本轮针对 agent_platform 的清理；此前 contracts.py 和其他模块的改动保留，不重复计入。

本轮修改 16 个生产文件，生产代码净减少 425 行。`test_generation_workflow.py` 从 1,007 行降至 568 行，其中静态契约迁入已有 schemas 文件，迁移行数没有作为删除量重复统计。

## 已完成的代码调整

1. **移除旧契约与导出。** 工作流残留的静态 Schema 归入已有 `test_generation_schemas.py`，规格模块直接引用契约模块。终审索引契约和来源关系别名也归入 schemas，解除静态契约对 review、semantics 业务模块的反向导入。删除无消费者的导入、惰性 `__getattr__`、重复维护的 `__all__` 清单，以及用例评估中四个未接入执行链的旧 Schema。已有测试和真实校验脚本改为从所属模块导入。
2. **统一生成校验。** 图片区域、必填文本、文本身份规则归入已有 `test_generation_facts.py`；规划匹配、批次合并和最终用例去重共用 NFKC 规范化。三处跨度 Schema 复用已有定义；保留带 `head_end` 的特殊结构。删除未使用的文本函数和导入。
3. **复用事实绑定索引。** 事实校验直接复用 `binding_index`；每个终审批次只在需要时构建一次绑定索引、计算一次重复事实集合，所有差异共用。事实义务仍按原先的字段槽位和 assertion 统计，未扩大为文本模糊匹配。
4. **减少服务层重复处理。** 文档查询复用已有知识库仓储，候选查询沿用已解析来源快照；审批拒绝由统一生命周期入口结束节点；恢复计划保留修复和部分完成两个独立标志；运行详情和摘要共用响应头，摘要不加载大 JSON。
5. **收敛运行时规则。** 额度预留和 SDK 执行共用轮次解析，并将子 Agent 工具声明纳入能力判断；压缩预算统一归一化。顺序映射复用取消和续租执行器，成功及失败检查点共用 `_AgentMapCheckpoint`，保留累计 `failure_counts`。两条映射路径共用修复字段恢复和后处理入口。
6. **移除失去消费者的同步兼容。** 删除测试专用 SDK 同步桥和运行时同步替身分支；顺序映射迁移后无调用者的 SDK `run_agent` 转发入口也已删除。现有测试改为使用真实异步入口，未新增或执行 mock 测试。

并行和顺序调度仍保留各自必要的 Session、并发安全与完成顺序处理。跨工具边界、持久化恢复边界的事实校验及锁内状态复查继续保留。
